# OLX Clone (HTML & CSS Only)

A modern, responsive pixel-perfect clone of the OLX marketplace web interface built entirely with pure HTML5 and CSS3.

This project demonstrates semantic markup, advanced CSS styling, and responsive layout techniques without relying on external frameworks or JavaScript.

---

## 🚀 Live Demo

Check out the live deployment of the project here:  
👉 **[Live Demo Link](https://hassanbinzubair.github.io/olxclone**)

---

## ✨ Key Features

- **Pixel-Perfect UI:** Closely mimics the official OLX web layout, typography, and spacing.
- **Component-Based Styling:** Features structured layouts for navigation, product grids, and footers.
- **Pure HTML/CSS:** Zero dependencies, zero frameworks, and zero JavaScript.
- **Semantic HTML5:** Built using SEO-friendly elements like `<header>`, `<nav>`, `<main>`, and `<footer>`.
